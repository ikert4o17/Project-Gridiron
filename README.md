# Project Gridiron 🏈

Project Gridiron is an open-source football analytics platform focused on the NFL and FBS College Football.

## Goals

- Predict game winners
- Predict point spreads
- Predict totals
- Generate win probabilities
- Calculate betting value
- Produce power rankings
- Track model accuracy over time

## Planned Features

### NFL
- Power Ratings
- Elo Ratings
- Offensive/Defensive Efficiency
- Injury Adjustments
- Weather Adjustments
- Betting Model

### College Football
- Team Ratings
- Strength of Schedule
- Recruiting & Transfer Portal Adjustments
- Conference Strength
- Betting Model
